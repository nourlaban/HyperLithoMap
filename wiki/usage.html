Quick Start & CLI Reference

Everything you need to go from raw satellite data to published geological maps in a single command, plus the complete Python API for scripted workflows.

◆ Installation

1
Clone the repository 
git clone https://github.com/nourlaban/HyperLithoMap.git
cd HyperLithoMap
2
Create a Python environment 
conda create -n pbhsdl python=3.10 -y
conda activate pbhsdl
3
Install dependencies 
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
pip install rasterio numpy scipy scikit-learn matplotlib
pip install xgboost einops causal-conv1d mamba-ssm

Requires CUDA 11.8+ for S²Mamba and SpectralFormer GPU training.

4
Place your data 
data/
└── RabshimamabadataPrisma/
    └── input/
        ├── PRISMA_Rabshi_clip.dat
        ├── PRISMA_Rabshi_clip.hdr
        ├── plate.clr
        └── PRISMA_Rabshi_dataset/
            └── Rabshi_PRISMA.shp  (+ .dbf, .prj, .shx)

◆ Fastest Path: One Command

# Run the complete pipeline: convert → label → split → train all 4 models
python main.py run-all --dataset RabshiPRISMA --verbose

# Export publication figures from the finished prediction maps
python -m preprocessing.export_figures --dataset RabshiPRISMA --dpi 300 --bar-km 5
Expected runtime: preprocessing ≈ 2 min · RF/XGB ≈ 5 min · S²Mamba 200 epochs ≈ 25 min · SpectralFormer 200 epochs ≈ 35 min (NVIDIA RTX 3090).

◆ CLI Reference

Global flags

FlagDefaultDescription
--datasetPRISMA Which dataset config to load: PRISMA | EnMap | RabshiPRISMA
--verbose / -voffEnable INFO-level logging to console and log file

Subcommands

preprocess — run Steps 1–4 only

python main.py preprocess --dataset PRISMA --verbose

Converts raw satellite data, rasterises labels, applies colour table, and generates train/test masks. Useful when iterating on label shapefiles without re-training models.

train — run Step 5 on pre-existing masks

# Default: mamba + spectral_former
python main.py train --dataset EnMap --skip-preprocessing

# Specify individual models
python main.py train --dataset PRISMA --models random_forests xgboost
FlagChoicesDefault
--models / -m random_forests xgboost mamba spectral_former mamba spectral_former
--skip-preprocessingflag off — preprocessing is skipped if flag is present

run-all — full pipeline

python main.py run-all --dataset RabshiPRISMA

Equivalent to preprocess followed by all four models. This is the default production entry point.

export_figures — figure export module

# Export all prediction maps as publication PNGs
python -m preprocessing.export_figures --dataset RabshiPRISMA

# Options
python -m preprocessing.export_figures \
  --dataset RabshiPRISMA \
  --dpi 300 \
  --bar-km 5
FlagDefaultDescription
--datasetRabshiPRISMASatellite config to use
--dpi300Output resolution (dots per inch)
--bar-km5Scale bar length in kilometres

◆ Python API

All CLI commands are thin wrappers around importable Python classes. Use the API directly in Jupyter notebooks or automated scripts.

Config

from projutils.config import Config

cfg = Config(satellite_name="RabshiPRISMA")

# Key attributes
cfg.tifpath            # intermediate/vnir_swir_stackedd.tif
cfg.train_mask_path    # intermediate/train_mask.tif
cfg.shapefile_path     # input/PRISMA_Rabshi_dataset/Rabshi_PRISMA.shp
cfg.class_field        # 'Classvalue' for RabshiPRISMA
cfg.samples            # 1000 pixels per class
cfg.save_model_path    # output/experiments_003/saved_models/

# Switch satellite in-place (useful in notebooks)
cfg.reinit("PRISMA")

HyperspectralPipeline

from projutils.config import Config
from src.pipeline import HyperspectralPipeline

cfg      = Config(satellite_name="RabshiPRISMA")
pipeline = HyperspectralPipeline(cfg, verbose=True)

# Run all four preprocessing steps
pipeline.run_preprocessing()

# Get ordered list of class names for model training
all_classes = pipeline.get_class_info()
# → ['Hornfels', 'Limestone', 'Mudstone-siltstone', ...]

ModelRunner

from src.model_runner import ModelRunner, ModelType

runner = ModelRunner(config=cfg, verbose=True)

# Run a single model
runner.run_random_forests(all_classes)

# Run a selection
runner.run_multiple_models(
    [ModelType.MAMBA, ModelType.SPECTRAL_FORMER],
    all_classes
)

# Run everything
runner.run_multiple_models(
    [ModelType.RANDOM_FORESTS, ModelType.XGBOOST,
     ModelType.MAMBA, ModelType.SPECTRAL_FORMER],
    all_classes
)

◆ Reading Evaluation Results

Each model writes its evaluation to saved_models/<model_name>/evaluation_results.txt. The four metrics reported:

MetricSymbolRangeInterpretation
Overall AccuracyOA0–1 Fraction of test pixels correctly classified
Average AccuracyAA0–1 Mean per-class accuracy (equally weights rare classes)
Cohen's Kappaκ−1–1 Agreement above chance; >0.8 = strong agreement
Per-class accuracyAA_i0–1 Recall for each individual lithological class
