Configuration Guide

Note: datasets are now declared in configs/datasets.yaml instead of if/elif blocks in projutils/config.py, and the experiment folder is chosen with --experiment rather than by editing current_stamp. The parameters described below keep the same names and meaning; see the README section “Configuring a Dataset” for the YAML syntax.

All paths, band lists, sampling settings, and experiment identifiers live in a single file: projutils/config.py. There are no environment variables, no YAML files to juggle — changing a number in config.py is the full story.

◆ Config Class Anatomy

# projutils/config.py — structure overview

class Config:
    def __init__(self, satellite_name="PRISMA"):
        self._init(satellite_name)

    def reinit(self, satellite_name):
        """Mutates this instance in-place — all existing references see new paths."""
        self._init(satellite_name)

    def _init(self, satellite_name):
        # ── 1. Satellite-specific block ─────────────────────────────────
        if satellite_name == "PRISMA":        ...
        elif satellite_name == "EnMap":       ...
        elif satellite_name == "RabshiPRISMA": ...

        # ── 2. Derived paths (shared, computed from above) ───────────────
        self.tifpath         = intermediate_dir / 'vnir_swir_stackedd.tif'
        self.train_mask_path = intermediate_dir / 'train_mask.tif'
        ...

        # ── 3. Sampling settings ─────────────────────────────────────────
        self.samples   = 1000
        self.test_size = 0.70

        # ── 4. Auto-create all required directories ──────────────────────
        self._create_required_dirs()

# Module-level singleton — imported by all pipeline components
config = Config()

◆ Adding a New Satellite

Adding support for a new sensor type requires changes in four files. Follow these steps in order.

1
Add conversion function — preprocessing/converth5totiff.py

Write a function that reads your raw format and writes a float32 GeoTIFF with nodata=−9999. Follow the pattern of convert_dat_to_stacked_tiff():

def convert_mysat_to_stacked_tiff(input_path, output_tiff_path, bands_to_remove=None):
    with rasterio.open(input_path) as src:
        data = src.read().astype(np.float32)
        transform, crs = src.transform, src.crs
    # remove bad bands, mask nodata, write output...
2
Add config block — projutils/config.py

Add an elif branch in _init():

elif self.satellite_name == "MySatellite":
    self.base_data_dir  = "data/my_satellite_data"
    self.input_data_dir = os.path.join(self.base_data_dir, 'input')
    self.intermediate_dir = os.path.join(self.base_data_dir, 'intermediate')
    self.output_dir     = os.path.join(self.base_data_dir, 'output')
    current_stamp       = "001"
    experiments_id      = f"experiments_{current_stamp}"

    self.scene_id       = "my_scene.tif"
    self.scene_path     = os.path.join(self.input_data_dir, self.scene_id)
    self.shapefile_path = os.path.join(self.input_data_dir, 'labels', 'labels.shp')
    self.bands_to_remove = []        # list zero-indexed bad bands
    self.class_field    = 'Classcode'
    self.clr_path       = os.path.join(self.input_data_dir, 'palette.clr')
3
Add pipeline branch — src/pipeline.py

Update the import and add an elif in _step_convert_satellite_data():

from preprocessing.converth5totiff import (
    convert_h5_to_stacked_tiff, convert_enmap_to_stacked_tiff,
    convert_dat_to_stacked_tiff, convert_mysat_to_stacked_tiff  # add this
)

# inside _step_convert_satellite_data():
elif self.config.satellite_name == 'MySatellite':
    convert_mysat_to_stacked_tiff(
        input_path       = self.config.scene_path,
        output_tiff_path = self.config.tifpath,
        bands_to_remove  = self.config.bands_to_remove
    )
4
Register CLI choice — main.py

Add the new name to both choices lists in add_common_args() and the parent parser:

choices=['PRISMA', 'EnMap', 'RabshiPRISMA', 'MySatellite']
5
Test end-to-end 
python main.py run-all --dataset MySatellite --verbose

Check that intermediate/vnir_swir_stackedd.tif is created with the expected band count, CRS, and nodata value before proceeding.

◆ Experiment Management

Each experiment version is isolated by a short current_stamp string inside the satellite block. Bumping the stamp creates a new output directory without touching previous results.

# In the PRISMA block of projutils/config.py:
current_stamp = "003"          # → output/experiments_003/

# To start a new experiment with different hyperparameters:
current_stamp = "004"          # → output/experiments_004/
Tip: You can also use a timestamp stamp for fully unique runs: 
from datetime import datetime
current_stamp = datetime.now().strftime("%Y_%m_%d_%H_%M_%S")
This is already in the code as a commented-out alternative on the line above current_stamp = "003".

◆ Tuning Model Hyperparameters

Deep model hyperparameters are in the Args class at the top of each demo file. They are plain Python class attributes — no CLI flags, no config file lookup. Edit the value directly and re-run.

S²Mamba — hsmodel/demo_mambaStateSpaceModel.py:22–35

AttributeCurrentNotes

◆ Adjusting Sampling Settings

ScenarioSettingValue
Quick iteration / few labelled polygons config.samples 200–500 (fewer pixels → faster; less accurate)
Full accuracy evaluation config.samples 1000 (default)
Severe class imbalance in shapefile config.samples Reduce to match the smallest class size
More training data, smaller test set config.test_size 0.50 (50/50 split instead of 30/70)
Strict hold-out evaluation config.test_size 0.80 (train only 200, test on 800)

◆ Identifying and Removing Bad Bands

Bad bands are spectral channels dominated by atmospheric absorption or sensor noise. They carry no useful geological signal and should be excluded before training. Typical windows to remove:

Wavelength rangeCausePRISMA bands (approx)
1350–1450 nm Water vapour absorption SWIR bands 40–56
1800–1950 nm Water vapour absorption SWIR bands 86–111
2450–2500 nm CO₂ + detector edge noise SWIR bands 152–171
First 5 VNIR bands Detector warm-up artefact VNIR bands 1–5

To identify bad bands for a new sensor, plot the mean spectrum across valid pixels and look for channels with near-zero or highly variable reflectance:

import rasterio, numpy as np, matplotlib.pyplot as plt

with rasterio.open("intermediate/vnir_swir_stackedd.tif") as src:
    data = src.read()                       # bands × H × W

nodata = -9999.0
means = []
for b in range(data.shape[0]):
    valid = data[b][data[b] != nodata]
    means.append(valid.mean() if len(valid) > 0 else np.nan)

plt.plot(means)
plt.xlabel("Band index"); plt.ylabel("Mean reflectance")
plt.title("Mean spectrum — identify near-zero bands")
plt.show()

◆ Colour Table (.clr) Format

The .clr file maps integer class values to RGBA colours and human-readable labels. It is a plain-text file where each row is:

value  R  G  B  alpha  Class_Label

Example (plate.clr for Rabshi PRISMA):

1   130  80  50  255  Hornfels
2    60 100 200  255  Limestone
3   200 160  60  255  Mudstone-siltstone
4   180  60  80  255  Phyllite
5    90 180  90  255  Quartzite
6   220 200  60  255  Sandstone
7    60 160 180  255  Serpentinite
8   180  80 180  255  Skarn

The export_figures.py module reads this file via _parse_clr() and builds the matplotlib ListedColormap used in all publication figures. If no .clr file exists, a default 10-colour palette from matplotlib's tab10 is used as fallback.
