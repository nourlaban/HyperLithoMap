Model Architectures & Comparison

HyperLithoMap includes four classifiers at increasing levels of architectural complexity. Classical tree methods (RF, XGBoost) treat each pixel as an independent spectral vector; deep models (S²Mamba, SpectralFormer) jointly model the 5×5 spatial neighbourhood together with inter-band spectral structure.

◆ Spatial–Spectral Input Construction

Classical models see one pixel at a time: a 234-dimensional feature vector. Deep models see a centred 5×5 neighbourhood, giving contextual information about mineral boundary gradients and mixed-pixel transitions.

◆ Random Forest

Architecture

Ensemble of decision trees trained via bagging (bootstrap aggregation). Each tree sees a random subset of features (bands) at each split node. Final class is the majority vote across all trees.

  • Input: 234-dim spectral vector per pixel
  • No spatial context — each pixel independent
  • Non-parametric, no normalisation required
  • Feature importance scores available

When to use RF

  • Rapid baseline without GPU
  • Interpretability needed (band importance)
  • Small training sets (<500 pts/class)
  • First experiment on a new scene

◆ XGBoost

Architecture

Gradient-boosted decision trees where each successive tree corrects the residual errors of the previous ensemble. Uses second-order gradients, L1/L2 regularisation, and column/row subsampling for efficiency.

  • Input: 234-dim spectral vector
  • Typical OA gain of +1–2 % over RF on hyperspectral data
  • Built-in handling of class imbalance via scale_pos_weight

When to use XGBoost

  • Best classical model — use instead of RF when performance matters
  • When GPU is unavailable but deep model quality is needed
  • Fast iteration on hyperparameter tuning
Code: hsmodel/demo_eXtremeGradientBoosting.py

◆ S²Mamba — Spectral-Spatial Mamba

Reference: Wang et al. (2025) — S²Mamba: A Spatial-Spectral State Space Model for Hyperspectral Image Classification. Architecture file: hsmodel/s2mamba.py  ·  Demo: hsmodel/demo_mambaStateSpaceModel.py

Why Mamba for HSI?

Transformers model global pairwise attention in O(N²) time. For a 234-band spectrum, full self-attention is feasible, but for a 5×5×234 spatial-spectral token sequence it becomes expensive. Mamba uses a selective State Space Model (SSM) that processes sequences in linear time O(N) while learning which spectral positions to "remember" — crucial for modelling sharp absorption features at specific wavelengths.

Key properties

  • Linear-complexity selective SSM (Mamba block)
  • Dual-branch: spectral branch + spatial branch, fused at output
  • Depths = [1], dims = [64] — lightweight for pixel classification
  • Dropout on attention + path for generalisation
  • Achieves highest OA (99.57 %) among all four models

◆ SpectralFormer — Vision Transformer

Reference: Hong et al. (2022) — SpectralFormer: Rethinking Hyperspectral Image Classification with Transformers. Architecture file: hsmodel/vit_pytorch.py  ·  Demo: hsmodel/demo_SpectralFormer.py

Architecture

Applies multi-head self-attention along the spectral axis: the 234 bands are divided into overlapping groups of band_patches=3 consecutive bands. Each group becomes one token with a learned embedding. The transformer encoder models cross-band dependencies (e.g., the correlation between the Fe²⁺ absorption at 1000 nm and the clay Al-OH feature at 2200 nm).

Band-patch grouping

The gain_neighborhood_band() function in demo_SpectralFormer.py:114 creates a sliding window over the spectral dimension:

  • Input: N × 5 × 5 × 234
  • After grouping: N × (5×5×3) × 234 = N × 75 × 234
  • Each of the 234 tokens contains 3 consecutive bands of the full patch

◆ Shared Utilities

Both deep models use the same data loading, normalisation, and evaluation functions from hsmodel/utils.py.

FunctionDescription
load_HSI(args) Loads stacked GeoTIFF + masks; applies nodata-aware per-band min–max normalisation. Critical: excludes −9999 pixels from min/max to prevent spectral collapse.
chooose_train_and_test_point() Reads train_mask/test_mask TIFs; returns per-class pixel coordinates and counts.
mirror_hsi() Pads the image by patch//2 on each side (mirror reflection) so that border pixels can use the full 5×5 neighbourhood.
train_and_test_data() Extracts 5×5 patches centred on each labelled pixel from the mirrored image.
train_epoch() / valid_epoch() Single epoch training / evaluation loops shared by Mamba demo.
calculate_metrics() Computes OA, AA, Kappa, and per-class accuracy from target/predicted arrays.
predict_whole_image() Runs full-scene inference using the model; used by Mamba (SpectralFormer uses its own chunked variant).
